### Learnings

#### 1. Hidden Files & Directories
Ever wondered why there are a lot of hidden folders and files in some directories on your PC? Well, those hidden files are not just random:
- They help prevent accidental deletion of important files on your system.
- They are generated by programs or the operating system for configurations and state.

#### 2. Essential CLI Commands
CLI commands that were lovely to add to my arsenal:
- `ls -R Document` — Lists directories and their contents in the specified directory (`Document` in this case). Running `ls -R .` will list all directories in the current folder and their contents.
- `history` — Gives a list of all past commands typed in the current terminal session.
- `history 15` — Shows the history for the last 15 commands run.
- `Ctrl + R` (or `Control + R`) — Interactive reverse search through command history.
- `uname` — Information about your operating system.
- `cat /etc/os-release` — Detailed information about your OS release.
- `lscpu` — Information about the CPU of your machine/system.
- `lsmem` — Memory information.

#### 3. Why Use CLI over GUI?
Why use Command Line Interface (CLI) over Graphical User Interface (GUI):
- You can be significantly more efficient.
- Easier for bulk operations.
- CLI is more powerful and scriptable.

#### 4. Linux Package Managers
- Used to download, install, or update applications from repositories.
- We do not need to worry about manual configuration because the package manager knows where to put all files in the Linux file system hierarchy.
- Every Linux OS distribution comes with a package manager already bundled.
- In Ubuntu, the `APT` package manager is readily available in the terminal.

#### 5. Alternative Ways for Installing Applications
- Via the Ubuntu Software Center (GUI).
- Snap package manager.
- Adding the repository to the official list of repositories using `add-apt-repository ...` and then installing the package as usual. The risk here, just like any unofficial application out there; there is no guarantee of security and one needs to be careful when going with this option.

#### 6. Vim (UNIX Text Editor)
For the first time, I accepted my fate and dove into the world of Vim. I must say it is very interesting the shift in experience, having to live on the terminal and use commands to navigate files and make edits. In the process of unlearning how heavily reliant I am on GUIs.

#### 7. Useful Commands within Vim Text Editor
- `dd` — Delete current line
- `u` — Undo
- `A` — Jump to end of line and activate insert mode
- `0` — Jump to start of the line and activate insert mode
- `12G` — Jump to line 12 (love this command)
- `/pattern` — Search for `pattern` (use `n` and `N` to jump through results found)
- `:%s/oldText/newText/g` — Find and replace every occurrence of `oldText` with `newText`
